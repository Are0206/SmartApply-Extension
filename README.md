# SmartApply Extension

Extensión de navegador para autocompletar formularios usando un perfil almacenado en una API segura.

## Arquitectura

- Extension (Chrome/Edge)
- Backend API
- Secure Mode (Preview + Log)

## Estructura

- extension/ → Código de la extensión
- backend/ → API
- docs/ → Documentación y entregables
